Style note: the app's actual existing Pixel Bunny (BITMAPS.bunny in kawaii-icons.tsx) is a single flat-accent-colored 8×8 silhouette icon — much more abstract than the shaded reference PNGs you shared (sleepy_emote / bunny_reading / sleeeping.PNG). The bunny's own shape, proportions, and single-tone accent color below stay faithful to that existing icon; the reference PNGs were only used for pose inspiration (hat shape, book stack, sleeping curl). Props (hat, books, desk, drone) get their own flat colors so scenes stay readable — the app already does this too (kawaii mode layers a pink blush + bow on top of the same accent silhouette).
